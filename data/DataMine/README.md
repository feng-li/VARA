# Accounting-Signal Risk Data

This directory contains the inputs for the Accounting-Signal Risk application.
The data are monthly returns for approximately 29,000 mechanically generated
long-short accounting strategies. One strategy is one panel series in the VARA
application.

## Source

The original data and replication code accompany:

> Andrew Y. Chen, Alejandro Lopez-Lira, and Tom Zimmermann, “Does
> Peer-Reviewed Research Help Predict Stock Returns?”

- Project repository: <https://github.com/chenandrewy/flex-mining>
- Public strategy-return files: <https://drive.google.com/drive/folders/1SZe_aF4ZNvK4ZRx2jQUE1j19KQvBaqWr>
- Paper: <https://arxiv.org/abs/2212.10317>

Download the public exports from the authors rather than committing them to
this repository. Record the download date and file hashes in
`data_manifest.yml` for reproducibility.

The strategy returns are public research outputs, but their construction uses
CRSP and Compustat. Those underlying security-level databases are proprietary
and are not distributed by this project. Users remain responsible for checking
the terms attached to the source data.

## Files used by VARA

| File | Description |
|---|---|
| `DataMinedLongShortReturnsEW.parquet` | Complete equal-weighted return panel; the source for the frozen application sample. |
| `DataMinedLongShortReturnsEW_21800.parquet` | Frozen 21,800-series equal-weighted panel used by default. It is generated by `scripts/extract_datamine_21800.py`. |
| `DataMinedLongShortReturnsVW.parquet` | Complete value-weighted panel for robustness analysis. |
| `DataMinedSignalList.parquet` | Formula metadata used to construct the attention features. |
| `DataMinedLongShortReturnsSample.parquet` | Small source-format sample for inspection or smoke tests. |
| `DataMinedLongShortReturnsEW_21800.manifest.json` | Provenance, hashes, selection dates, and selection rules for the frozen subset. |
| `data_manifest.yml` | Local inventory, source links, units, and SHA-256 hashes. |

CSV files with the corresponding names are the authors’ public exports. The
Parquet copies preserve their content while reducing storage and input time.
The metadata export may be named
`DataMinedLongShortReturnsSignalList.csv` upstream; this repository uses the
shorter local name `DataMinedSignalList`.

## Schema and units

Return files contain:

| Column | Meaning |
|---|---|
| `signalid` | Accounting-strategy identifier and metadata join key. |
| `year`, `month` | Calendar month of the return. |
| `ret` | Monthly long-short return, supplied in percentage points. |
| `nstock` | Portfolio coverage used by the application’s sample-quality rules. |

The ingestion code converts `ret` from percentage points to decimal returns.
Missing strategy-month rows remain missing; they are not imputed. The metadata
file contains `signalid`, `signal_form`, `v1`, and `v2`, describing the formula
type and its two accounting ingredients.

The frozen 21,800-series file retains all observed rows for strategies meeting
the pre-validation quality rules over January 1988–December 2007. Generate it
from the complete EW Parquet file and metadata with:

```bash
python scripts/extract_datamine_21800.py
```

The default application input is configured in `primary.yml`. The detailed
preparation and forecasting procedure is documented in `workflow.md`.

## Git policy

All contents of this directory are ignored by Git except the lightweight
configuration and documentation explicitly allowed by the repository
`.gitignore`. In particular, CSV, Parquet, PDF, manifest, and copied upstream
replication files remain local. Do not force-add these large or externally
sourced artifacts.
